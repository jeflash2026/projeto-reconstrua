Política de Privacidade

Uma explicação curta e direta sobre o funcionamento deste site e do atendimento iniciado pelo WhatsApp.

1. Este site não coleta dados

Este site não possui formulários, não solicita dados pessoais durante a navegação e não utiliza cookies de rastreamento, Pixel ou Google Analytics.

2. O contato acontece pelo WhatsApp

Ao escolher falar com o escritório, o atendimento é iniciado no WhatsApp. As informações e os documentos enviados nesse atendimento são utilizados apenas para analisar o caso e, havendo contratação, prestar o serviço jurídico correspondente.

3. Acesso, correção ou exclusão de dados

Para solicitar acesso, correção ou exclusão dos dados fornecidos durante o atendimento, envie uma mensagem para cnh@projetoreconstrua.com.br.
